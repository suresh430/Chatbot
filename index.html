Cloudify docs chatbot

This hosts the embeddable support chatbot for Cloudify. Try it right now — click the chat bubble in the bottom-right corner.

The same widget can be embedded on any page with one script tag. Static assets:

  • chatbot-widget.js — the chat widget (embed it on any page)
  • kb.json — the knowledge base, rebuilt nightly from docs.cloudify.biz

Questions? Contact the Cloudify team.
